HƯỚNG DẪN CHẠY ỨNG DỤNG TRÍCH XUẤT THÔNG TIN TUYỂN DỤNG

1. Yêu cầu hệ thống:
- Đã cài đặt Python (khuyên dùng bản 3.8 - 3.10).

2. Cài đặt các thư viện cần thiết:
Mở Terminal / Command Prompt tại thư mục này và chạy lệnh:
pip install PyQt5 PyMuPDF requests beautifulsoup4 trafilatura

3. Chạy ứng dụng:
Sau khi cài xong thư viện, chạy lệnh:
python run_app.py

Lưu ý: 
- File "hello_kitty_4.png" phải nằm cùng thư mục với file "run_app.py".
- Các file "ui_main_window.py" và "resources_rc.py" không được xóa.
